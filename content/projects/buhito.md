**Problem.** Graphlets (small connected subgraphs) give interpretable features for molecules and other graph data, but enumerating them efficiently across large datasets needs dedicated tooling.

**Method.** buhito is a Python library for enumerating graphlets and analyzing graphlet-based features on any graph-like data, with DFS/BFS traversal and a benchmarking suite. I am the lead developer.

**Result.** Released as open source by Los Alamos National Laboratory; I secured project funding as Co-I. Related talks: "Fantastic Molecular Graphlets and Where to Use Them" (invited talk, MLCM-26, 2026) and "Graphlet-Induced Learning for Interpretable and Data-Efficient Cheminformatics" (poster, ChemAI NYC 2026).
